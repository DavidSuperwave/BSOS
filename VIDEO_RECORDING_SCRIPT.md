# Video Recording Script - Research Workflow

## Pre-Recording Checklist

- [ ] Screen recording software ready (OBS, Loom, QuickTime, or similar)
- [ ] Audio microphone tested
- [ ] Browser open to Blitzscale OS dashboard
- [ ] Company selected (Superwave or test company)
- [ ] Chat interface open
- [ ] PlusVibe dashboard accessible (for final verification)
- [ ] Environment variables configured (Perplexity, PlusVibe, Supermemory)

## Video Script (3-5 minutes)

### Introduction (0:00 - 0:30)

**Narration:**
"Today I'm going to show you our new research workflow feature. This allows you to research target markets, generate email scripts, and create campaigns - all directly from the chat interface. Let me show you how it works."

**Screen Actions:**
- Show the Blitzscale OS dashboard
- Navigate to Chat interface
- Point out the chat input area

---

### Step 1: Research Command (0:30 - 1:00)

**Narration:**
"First, I'll research 'Marketing agencies' based on my company profile. I'll type a natural language command asking the agent to research the topic and generate email scripts."

**Screen Actions:**
- Type in chat: `Research "Marketing agencies" based on my company profile and generate 3 email scripts. Use David@superwave.ai as the sender.`
- Press Enter
- Show the message appearing in chat

**What to Highlight:**
- Natural language command
- No complex syntax needed
- Agent understands the intent

---

### Step 2: Agent Processing (1:00 - 1:45)

**Narration:**
"Now you can see the agent is processing. It's calling the research tool, which will:
- Fetch my company profile
- Research the topic using Perplexity AI
- Generate 3 email scripts
- Store everything in Supermemory"

**Screen Actions:**
- Show tool calls appearing (if visible in UI)
- Show "thinking" or processing indicator
- Point out the different steps happening

**What to Highlight:**
- Multiple steps happening automatically
- AI-powered research
- Context-aware (uses company profile)

---

### Step 3: Research Results (1:45 - 2:30)

**Narration:**
"Great! The research is complete. You can see:
- Comprehensive research about marketing agencies
- 9 citations from reliable sources
- Three email scripts generated, each with a different angle:
  1. Infrastructure Pain angle
  2. Data Quality angle  
  3. Scale Without Hiring angle

Each script is under 75 words, includes personalization placeholders, and has a clear call-to-action."

**Screen Actions:**
- Scroll through the research results
- Highlight the email scripts
- Show the different angles
- Point out personalization placeholders ({{firstName}}, {{company}})

**What to Highlight:**
- Quality of research
- Variety of email scripts
- Professional formatting

---

### Step 4: Supermemory Storage (2:30 - 2:45)

**Narration:**
"Notice that all this research has been automatically stored in Supermemory. This means the agent can reference it in future conversations, and our knowledge base grows automatically."

**Screen Actions:**
- Mention Supermemory storage (if visible)
- Or explain it's happening in the background

**What to Highlight:**
- Automatic knowledge storage
- Future reference capability

---

### Step 5: Campaign Creation (2:45 - 3:30)

**Narration:**
"Now let's create a campaign using these scripts. I'll ask the agent to create a campaign with all three email scripts."

**Screen Actions:**
- Type: `Create a campaign called "Marketing Agencies Q1 2025" using all 3 email scripts from the research.`
- Press Enter
- Show the campaign creation process

**What to Highlight:**
- Seamless transition from research to campaign
- Uses the scripts we just generated
- Natural language command

---

### Step 6: Campaign Created (3:30 - 4:00)

**Narration:**
"Perfect! The campaign has been created in PlusVibe. You can see:
- Campaign ID
- Three email sequences configured
- Wait times set (1 day, 3 days, 5 days)
- All scripts properly formatted

The campaign is now ready to add leads and activate."

**Screen Actions:**
- Show the campaign creation confirmation
- Show campaign details
- Optionally: Open PlusVibe to show the actual campaign

**What to Highlight:**
- Campaign created successfully
- Sequences configured correctly
- Ready to use

---

### Step 7: Verification (4:00 - 4:30)

**Narration:**
"Let me quickly verify the campaign in PlusVibe to show you it's all set up correctly."

**Screen Actions:**
- Switch to PlusVibe dashboard (or show in new tab)
- Navigate to the campaign
- Show the email sequences
- Show the subject lines and email bodies

**What to Highlight:**
- Campaign exists in PlusVibe
- Sequences are correct
- Email content is properly formatted

---

### Conclusion (4:30 - 5:00)

**Narration:**
"And that's it! In less than 30 seconds, we've:
- Researched a target market
- Generated 3 professional email scripts
- Stored everything in our knowledge base
- Created a fully configured campaign

All from a simple chat conversation. The research workflow makes it incredibly easy to go from idea to campaign in minutes, not hours."

**Screen Actions:**
- Show a summary view
- Highlight the key benefits
- End with the chat interface

**What to Highlight:**
- Speed and efficiency
- Ease of use
- Complete workflow

## Troubleshooting

If something doesn't work during recording:

1. **Research fails**: Check Perplexity API key
2. **Scripts not generated**: Check API response format
3. **Campaign creation fails**: Check PlusVibe credentials
4. **Supermemory storage fails**: Check Supermemory API key
